# Color Theme Variants

## Variant 1 — Current Theme (Primary)

### Core palette
- **Primary background gradient**: `#07131f` → `#0f2b45`
- **Primary text**: `#f8f7f2`
- **Primary accent**: `#f0c36d`
- **Secondary accent**: `#f7d79b`
- **Muted text / body copy**: `#dfe6ec`, `#d5d5d5`, `#e4e4e4`
- **Panel / card surface**: translucent white overlays like `rgba(255, 255, 255, 0.03)` and `rgba(255, 255, 255, 0.06)`
- **Strong panel border / divider**: `rgba(255, 255, 255, 0.1)`

### Usage summary
- The site uses a deep navy/indigo base with warm gold highlights for buttons, badges, and interactive states.
- Text is mainly a bright off-white tone on dark backgrounds to maximize readability.
- Secondary information and descriptions use softer off-white shades.
- UI panels and cards rely on subtle translucent surfaces and gentle glass-like blur backgrounds.
- Primary action buttons are gold with dark text, while secondary buttons and outlines use lighter gold borders and soft white shading.

### Example token mapping
- `background`: `linear-gradient(135deg, #07131f 0%, #0f2b45 100%)`
- `text-primary`: `#f8f7f2`
- `accent`: `#f0c36d`
- `accent-light`: `#f7d79b`
- `surface`: `rgba(255, 255, 255, 0.05)`
- `border`: `rgba(255, 255, 255, 0.12)`
- `button-primary-bg`: `#f0c36d`
- `button-primary-text`: `#07131f`

## Variant 4 — Government / White Theme

### Core palette
- **Primary background**: `#ffffff`
- **Primary text**: `#111111`
- **Secondary text**: `#4d4d4d`
- **Subtle text**: `#6f6f6f`
- **Link / accent**: `rgba(0, 0, 0, 0.55)` with blurred/glass hover state
- **Panel / card surface**: `rgba(255, 255, 255, 0.9)` with subtle borders
- **Border / divider**: `rgba(0, 0, 0, 0.08)`
- **Button accent**: `#111111` or `rgba(0, 0, 0, 0.85)` for strong CTAs

### Usage summary
- The theme is inspired by government-style applications: clean, authoritative, and easy to read.
- Use white and near-white surfaces with crisp black typography.
- Accent links and interactive elements with a glassy black tint or light charcoal blur.
- Keep panels minimal and clear, with light borders instead of heavy shadows.
- Buttons should stay simple, bold, and grounded in black or charcoal.

### Example token mapping
- `background`: `#ffffff`
- `text-primary`: `#111111`
- `text-secondary`: `#4d4d4d`
- `accent`: `rgba(0, 0, 0, 0.55)`
- `surface`: `rgba(255, 255, 255, 0.9)`
- `border`: `rgba(0, 0, 0, 0.08)`
- `button-primary-bg`: `#111111`
- `button-primary-text`: `#ffffff`
